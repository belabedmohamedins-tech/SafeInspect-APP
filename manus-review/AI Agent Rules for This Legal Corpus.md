# AI Agent Rules for This Legal Corpus

Use these Markdown files as **derived retrieval references**, not as the legal authority. The source PDF or official Journal Officiel remains authoritative.

## Required behavior

Always cite the Markdown filename, instrument, article or annex, and source PDF page when answering from this corpus. Prefer files marked `human-verified` or `automated-high-coverage-human-review-required`; treat `partial`, `low-coverage`, `ocr-review-required`, `unmatched-source`, and `project-no-official-source` as non-definitive.

For exact quotations or claims involving numbers, dates, units, thresholds, deadlines, penalties, exceptions, amendments, repeal status, tables, annexes, or OCR text, require verification against the source PDF before presenting the answer as definitive.

Never invent missing text, silently correct OCR, merge different legal versions, infer an instrument’s identity from a source-only extraction, or treat repository notes and conversion metadata as legal provisions. If evidence is incomplete or conflicting, state the limitation and request source-PDF or human review.

## Safe answer format

**Answer:** State only what the cited passage supports.

**Source:** `filename.md`, instrument, article/annex, PDF page.

**Confidence:** State the file’s `quality_status` and whether PDF verification is required.

**Limitation:** Mention any OCR, table, annex, amendment, or coverage issue relevant to the answer.
