# legal_refs — Index des textes légaux de référence SafeInspect

> **Dossier canonique unique.** Tous les textes légaux de référence pour SafeInspect se trouvent dans `legal_refs/md/`.  
> `docs/legal_sources/` **a été supprimé définitivement** (confirmé le 2026-08-09 — voir `md/CLEANUP_LOG.md`). Ce dossier n'existe plus et ne doit pas être recréé.

Chaque fichier `.md` est une transcription verbatim du texte officiel publié au Journal Officiel de la République Algérienne (JORADP).  
Statut par défaut : ⚠️ NON VÉRIFIÉ — à vérifier contre le JORADP original avant tout usage légal.

## Structure du dossier

```
legal_refs/
├── README.md                  ← Ce fichier — index de tous les textes légaux
├── AGENT_INSTRUCTIONS.md      ← Règles de coordination inter-agents
├── md/                        ← Tous les textes légaux en Markdown (verbatim JORADP)
│   ├── audit.js               ← Script d'audit natif (ne pas déplacer)
│   ├── CLEANUP_LOG.md         ← Journal des opérations de nettoyage
│   ├── HANDOVER.md            ← Notes de passation
│   ├── SOURCE_MANIFEST.json   ← Manifeste des sources
│   └── *.md                   ← Textes légaux
├── pdf/                       ← PDFs originaux JORADP (SOURCE AUTORITAIRE — NE JAMAIS MODIFIER)
└── validation/
    ├── AUDIT_PROMPT.md
    ├── AUDIT_PROTOCOL.md
    ├── conversion_audit.md
    └── conversion_status.json
```

## Fichiers non-MD dans md/

> ℹ️ **`md/audit.js` appartient à ce dossier.** C'est le script d'audit natif qui analyse le contenu de `legal_refs/md/` (vérification des headers, séquences d'articles, cohérence README). Il est intentionnellement colocalisé avec les fichiers qu'il audite. **Ne pas le déplacer, ne pas le signaler comme anomalie.**  
> De même, `md/CLEANUP_LOG.md` est un journal d'opérations internes, pas un texte légal.
